## Главные выводы:

1. **JavaScript гибче C#** — можно менять типы переменных во время выполнения
2. **JavaScript проще синтаксически** — меньше церемоний и boilerplate кода
3. **JavaScript опаснее** — ошибки находятся только во время выполнения
4. **C# безопаснее** — компилятор не даст допустить многие ошибки на этапе разработки
5. **JavaScript лучше подходит для web-разработки** — встроенная поддержка браузеров
6. **C# лучше для enterprise-разработки** — строгая типизация и производительность
